## 版面與字級

內容頁不是照 PPT 的固定字級，而是由瀏覽器自動排版：

- 頁首上移、版心加寬，讓出內容空間；頁尾「資料來源」縮小。
- 同一頁的文字一起放大到排得下的最大（內文目標約 24–26px，原 PPT 是 16–19px），文字長高時下方內容自動往下推。
- 內容很滿的頁（大表格、長 Prompt）放大幅度較小。

## 更新線上版

重建後 `git add -A && git commit -m "說明" && git push`，約 1 分鐘後生效，網址不變。

## PPT 改版後重新產生

```bash
python tools/build.py "來源.pptx"
```

- `tools/build.py`：轉換器（讀 PPTX、版面分析、輸出 HTML）。
- `tools/patches.py`：**依原 PPT 頁碼**做的內容調整。`INSERTS` 可把同資料夾裡的其他 PPTX 插在指定頁之後（頁碼用「基數＋該檔頁次」，例如 201）；1600×900 的來源會自動換算成 1280 寬（刪頁、刪卡片、改字、改色、重點標註、指定加大）。PPT 頁序變動時要跟著改頁碼；找不到指定文字時 build 會停下來並指出是哪一頁。
- `tools/template.html`：播放引擎、樣式、自動排版與互動程式。
- `tools/interactive.html`：互動頁內容，以 `<!--@原頁碼-->` 標示要取代 PPT 的哪一頁。
- `tools/custom.html`：手工重新設計的頁，標示方式相同；`@@IMG:名稱@@` 會嵌入 `tools/images/名稱.jpg`。
- `tools/check.js`：版面自動檢查（文字重疊、超出卡片、壓到來源列），用法寫在檔案開頭。
